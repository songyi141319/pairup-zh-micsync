# Windows 设备音量联动（2026-10-14）

## 本次调整

以前 PairUp 的单台音量只是程序内部的衰减比例，Windows 设备属性中的音量是另一层限制。例如程序显示 100%，系统设备仍可能只有 39%。主音量也没有同步修改所有输出的系统音量。

现在以 Windows 的设备音量为准：

- 调 PairUp 主音量，当前音源和开启转发的输出设备一起设为该百分比。
- 在 Windows 快捷面板或用键盘音量键调整当前音源，已开启的输出也会跟随。程序运行时约每 250 毫秒读取一次系统状态，收起到托盘后仍有效。
- 单独调一台音箱，只调整该台的 Windows 设备音量；从系统属性页改音量，也会反映到 PairUp。下一次主音量变化会把参与播放的设备重新统一到主音量数值。
- 没有开启转发的设备不跟随主音量。手动新开启的输出加入当前主音量；启动恢复旧设备时只读取系统现有音量，不把以前保存的程序比例写回系统。
- 普通转发不再叠乘“主音量 × 单台比例”。静音状态保留，不因设置百分比而强行打开静音的音箱。
- 校准期间暂停联动，原来的校准隔离、结束恢复和捕获失败静音处理保留。

每个音箱自身的功率、硬件旋钮和声音驱动仍可能不同，相同百分比不代表听起来完全一样响。本次统一的是设备音量，不改其他播放器的应用音量或音箱硬件旋钮。

## 使用

正常退出旧版（托盘右键选择退出），打开本次新版即可。先把 Windows 音量设到舒适水平；新版读取系统音量，旧版软件衰减不再额外叠加。改变 Windows 默认音源后仍请正常退出并重开，以重新选择捕获音源。
