# 声屿 Implementation Plan

**Goal:** 增加音乐音场分工并迁移用户指定玻璃界面。
**Architecture:** 原生音频后端保留，离线 WebView2 页面通过白名单与既有视图模型连接。两个实现模块互不编辑对方文件。
**Tech Stack:** .NET 8 WPF, NAudio 2.2.1, WebView2, 离线 Sam Asante / React 玻璃组件。
**Spec:** ../specs/2026-10-14-shengyu-design.md

## 全局限制
保留所有已有未提交修复，不替换现用程序、不播放音频。音效测试只使用合成内存数据。标题中文，版权名称不修改。外部页面不能进入宿主桥。校准旁路音效并拒绝参数修改。

## 审查重点
旧设置加载零变化；立体声转单声道前分配位置；校准不被低通阻断；恶意/无效桥接参数拒绝；窗口退出后没有遗留定时器/玻璃实例。
