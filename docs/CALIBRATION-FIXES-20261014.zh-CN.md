# 自动校准修复（2026-10-14 本机预览版）

本次包含 Windows 音量联动修复，尚未上传 GitHub。

## 改动

- 每次打开校准窗口，默认勾选主界面已开启的输出设备。当前音源始终作为基准。取消了根据“耳机”名称排除设备的判断，Realtek AUX 不再漏选。
- 测量前检查设备是否在线、输出是否静音、设备音量和 PairUp 应用音量是否为零；不擅自调高音量。麦克风静音或输入音量为零会明确提示。
- 检查测试音播放异常和提前停止，避免全部归为“参考音不清楚”。
- 区分电脑内部参考音读取失败和麦克风未识别到音箱；每轮失败注明设备、轮次和读取到的 Windows 设备音量。
- 没有麦克风或未选择麦克风时给出明确提示。详细失败信息放在可滚动的结果区域。
- 沿用失败不应用新延迟、取消后恢复原播放状态的机制。

## 适用边界

设备音量百分比不能证明实际声压。音箱硬件音量、Windows 中 PairUp 的应用音量、摆放位置、环境噪声和蓝牙连接都会影响测量。内部参考音正常也不代表音箱一定发声。

此前失败没有足够现场记录，不能确定都由音量过低引起。这次修复明确的漏选问题，并补齐失败检查和提示；不保证所有蓝牙设备都能自动校准成功。仅在全部测量可靠时应用延迟。

本轮进行编译和静态代码审查，不播放测试音，不录音，也不运行自动测试。真实麦克风校准仍待用户实际使用确认。
