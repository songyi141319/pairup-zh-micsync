# 声屿：音乐音场与玻璃界面

声屿把原来的音箱控制整理为“播放、音场、摆放指南、外观”四个页面。原来的音量、精确延迟、均衡器、收藏、同步校准、访客分享、刷新、更新与原版界面入口继续保留。

设备名称直接显示 Windows 提供的完整名称，较长名称会换行，悬停也能看到完整文字。播放、音场、预设与访客分享使用同一设备名称，不用概称替换真实设备。

## 怎么开始

1. 先在 Windows 中连接蓝牙或有线音箱，然后在“播放”页刷新设备。
2. 打开想参与播放的转发音箱。主音源由 Windows 直接播放，页面会明确标记“主音源 · 原声直出”。
3. 把音箱摆好，先打开声音校准，让不同音箱尽量同时到达，再调整音色或音场分工。
4. 在“音场”选择全屋同播、左右立体声、音乐环绕或低音辅助，手动勾选已开启转发的音箱，并确认每只音箱的位置和能力。
5. 应用预设只改变声音角色、频率范围与分工衰减；不会自动开启音箱，也不会改变音量或同步延迟。

## 四种听法

| 预设 | 做什么 | 需要先确认 |
| --- | --- | --- |
| 全屋同播 | 每只所选音箱播放完整立体声音乐；频段不限、分工衰减为零 | 勾选已开启的转发设备及其能力 |
| 左右立体声 | 将左、右内容交给明确指定的音箱 | 左、右至少各一只；主音源不能被转发链重新分配 |
| 音乐环绕 | 用户指定前方或侧后角色，侧后以较轻的声音加入 | 至少一只侧后角色；小音箱以 100 Hz 低频截止作为起点 |
| 低音辅助 | 所选音箱以 100 Hz 高频截止、−3 dB 衰减作为起点 | 必须明确具备低频能力，不能按型号或名称猜测 |

这些数值是可调整的起点，不代表对所有设备最佳。侧后分工默认 −6 dB。完整音乐角色且两个截止为 0、衰减为 0 时，新增音场处理保持原声旁路。

音乐环绕是立体声音乐的模拟扩展，不是原生独立 5.1、杜比全景声解码或杜比认证。中置播放左右的共同内容，并非 AI 人声分离。音箱位置决定从哪里听到声音；频段决定音箱播放哪些高低音，两者需要分别设置。实际音色取决于设备能力、摆放、房间与音源。

“赫兹（Hz）”表示频率；低频截止会移除更低的声音，高频截止会移除更高的声音，0 表示不限。“分贝（dB）”表示声音增减；分工衰减只允许 −24 至 0 dB，负数让分工声更轻。延迟可以按 0.1 毫秒调整，范围 0–3000 毫秒。

## 摆放建议

从固定的中心听音位置出发，前方左右尽量对称，朝向座位，出音位置尽量接近坐下时的耳高。用于音乐环绕的小音箱可放在座位侧后方，先小声加入。

低音炮可以在房间前侧试几个位置，改变与墙面距离，比较是否轰鸣、低音是否均匀。墙角可能增强某些低音，也可能让低音更不平坦。普通小音箱滤掉高音后不会因此具备低音炮能力。

每次只改变一件事：先摆放与同步，再调整频段和分工声量，最后回到座位听熟悉的音乐。

参考：[Dolby 官方音箱摆放指南](https://www.dolby.com/about/support/guide/speaker-setup-guides/5.1-virtual-speakers-setup-guide/)，用于中心听音位置、朝向与耳高原则；[Genelec 低音炮摆放与低频管理](https://www.genelec.com/en/subwoofer-placement-bass-management)，用于房间与边界对低频的影响。此界面不承诺参考图所示的原生多声道解码能力。

## 玻璃外观

在“外观”选择跟随系统、浅色或深色，可以单独关闭薄荷、蓝、紫、粉彩氛围光。三档透感为经典、更透、清晰；默认经典。切换透感不覆盖已设置的 DIY 参数。

“打开玻璃调节”提供 31 项参数：内容、侧栏、浮层与工具栏透明度；两种模糊；三种圆角；深度、边缘弯曲、边缘厚度、反光、高光厚度；鼠标亮边强度、感应范围、光斑大小与亮边厚度；折射强度、曲率、色散、角部展开；高光强度、角度和衰减；辉光强度、范围和衰减；霜化、饱和度、明暗。

浮层标题可以拖动。聚焦标题后用方向键移动，Shift 加方向键加大移动幅度，Home 复位，Esc 关闭。参数自动保存在本机，存储不可用时本次会话仍能调整。系统“减少动态、高对比、降低透明度”会触发相应降级。

## 彩色波形

播放页使用 React Bits 的 Strands 彩色波形。它是装饰，不代表实时音频电平，也不读取麦克风。外观页的“彩色波形”提供实时预览和全部 18 项调节：配色、线条数量、速度、幅度、波纹密度、粗细、辉光、渐隐、展开、强度、色彩浓度、不透明度、缩放、玻璃球开关、折射、色散、玻璃球大小和色相。

默认橙、紫、青三色，数量 3、速度 0.5、幅度 1、波纹密度 3、粗细 0.7、辉光 2.6、渐隐 0.5、展开 1、强度 0.5、色彩浓度 2、不透明度 1、缩放 2.2；默认使用波形模式，折射 1、色散 1、球体占比 1、色相 0。可添加最多 8 色，移除全部颜色时显示组件内置彩虹。“恢复动效配方”只重置这 18 项，不改变布局、液态玻璃配方或音箱设置。

“形态与尺寸”单独控制摆放：波形长度 20–100%，高度 80–320 像素，可靠左、居中或靠右；玻璃球区域 80–320 像素，保持正圆。默认波形铺满文字旁的留白，高度 150 像素、居中；球形区域默认 200 像素。切换“波形 / 玻璃球”时，各自尺寸都会保留。小窗口将文字与动效上下排列，球形区域在必要时等比缩小。

快捷尺寸有铺满（100%、150 像素）、适中（60%、150 像素）、迷你（30%、100 像素）、玻璃球（200 像素）。快捷尺寸只改变布局和模式，保留颜色、流动、波纹等配方。“恢复布局”仅恢复长度、高度、对齐和球形区域四项，当前模式不变。布局使用独立的本机存储，正式程序与演示仍然分开。

关闭柔和动态、系统要求减少动态或速度调到零时显示静态帧。切换页面、窗口隐藏或波形离开可见区域时释放绘制资源。播放与调节预览最多同时保留一个波形实例，连同导航与浮层最多三个活动折射表面。

彩色波形需要浏览器支持 WebGL 2（绘制这类动画的图形能力）。不支持或绘制程序准备失败时，会关闭该装饰并显示说明，不会继续循环报错；音箱控制入口仍然保留。

## 离线界面演示

独立浏览器打开 `src/PairUp.App/Web/index.html?demo=1` 可以操作示例音箱，页顶和页底都有明显演示标记。没有 `?demo=1` 且没有应用连接时，页面不会伪装设备连接或操作成功。

原生 `--ui-preview` 由程序提供独立演示状态，通过与真实页面相同的消息接口往返。预览的录音、声音播放、设备枚举、真实设置、更新和访客服务隔离由宿主负责。普通浏览器的演示只在页面内修改示例数据。

连接接口在每次操作时重新取得，避免只在页面启动时判断。只要接收过主程序状态，后续即使连接接口暂不可用，也会拒绝操作，不会降级成页面内的演示成功。

真实外观和演示外观分别使用 `shengyu-app-v1-*` 与 `shengyu-preview-v1-*` 本机存储，不共享工作台设置，也没有加载工作台的 `user-profile.js` 迁移逻辑。

## 交互接口与验证入口

唯一设备接口是网页向宿主发送白名单消息，宿主通过 `window.shengyuReceive(state)` 回传实际状态；失败与分享资料通过 `window.shengyuMessage({message,error,link,pin,qr})` 返回。网页不开放任意本机命令。设备名称、状态、错误、分享地址作为纯文本显示，二维码只接受内联 PNG/JPEG/WebP 图像。

页面保留正在编辑的输入，避免后台状态刷新覆盖尚未应用的数值。模态说明支持 Esc、Tab 焦点约束与关闭后焦点恢复。外观浮层是非模态浮层，可与页面交互。

只读检查入口：`window.ShengyuUI.inspect()`、`window.ShengyuUI.getState()`、`window.ShengyuGlassAdapter.activeCount`、`window.ShengyuGlassContrastReport`、`window.ShengyuStrandsStatus`。对比度报告可先执行 `await window.ShengyuGlassContrast.refresh()` 更新，报告同时记录取样配方与实际计算的文字颜色，`computedTextSurfaces` 列出文字颜色、最低比值及低于 4.5 的项目。它依然属于背景取样计算，并非逐像素截图认证。

波形配方接口为 `window.ShengyuStrandsSettings.get()/set()/reset()`；数值控件选择器为 `[data-strands-setting=参数名]`，颜色为 `[data-strands-color]`，配方重置为 `#strands-reset`。布局接口为 `window.ShengyuStrandsLayout.get()/set()/reset()`，数值控件为 `[data-strands-layout=widthPercent|heightPx|sphereSizePx]`；对齐、模式和快捷尺寸分别使用 `[data-strands-align]`、`[data-strands-mode]`、`[data-strands-preset]`；布局重置为 `#strands-layout-reset`。模式仍由原配方的唯一 `glass` 字段决定，没有重复开关或第二份模式存储。

`window.ShengyuStrandsStatus` 提供活动实例数量、活动折射表面、动态/静态/隐藏状态、波形或球形模式、逻辑画布比例、当前布局与图形错误记录。横向适配使用固定比例的逻辑画布映射到显示尺寸，原始着色器不变，避免只扩大容器却不增加实际波形长度。

本地离线检查：在仓库根目录运行 `node src/PairUp.App/Web/checks.cjs`。原生截图和交互结果以实际 WebView2 验收记录为准；静态检查、演示和合成数据检查不能代替真实蓝牙听感。
