真实后台渲染截图及检查日志随 `v0.4.0-preview.2` 发布，设备状态为隔离示例。铺满、迷你、球形和设置页均使用本次实际页面绘制。原始组件及三个绘制程序的字节校验继续保留。

## 找到并修复的问题

1. **图形能力较旧时波形不断报错。** 旧暂存包在“只有 WebGL 1”和“绘制程序准备失败”两个受控情景中各出现约 300 次重复异常，且没有正确显示不可用说明。修复后先检查能力和两个绘制程序，失败即释放资源，五种情景均通过。没有更改原始波形算法或三个着色器。
2. **换电脑后固定源码被误判为已修改。** Windows 自动换行转换可能改变逐字节校验结果。现在对上游固定文件保留原字节，没有关闭哈希检查。
3. **主程序接口稍晚出现时可能误走演示路径。** 每次操作重新读取接口；接收过主程序状态后，断连只能显示失败，不能以本地模拟冒充操作成功。
4. **浅色校准卡文字颜色不正确。** 文字实际使用自适应颜色；回归同时核对实际样式，避免只检查配色计算结果。

旧图形代码、失败结果及其校验值单独保留在交付目录的 `验证/图形兼容旧包反例`，最终成功结果在 `验证/后台界面`。早期原生预览未完成的记录也予以保留，不计入上表的通过数量。

## 截图与设备状态的区别

截图来自真正加载当前页面的后台 Chromium 浏览器，没有生成或拼接 UI。为了遵守“不操控电脑”，浏览器不显示窗口，音箱状态由隔离的示例数据提供。示例包含用户此前提供的 Windows 名称，用来检查长名称显示，不代表这些设备目前在线。

截图包括播放、音场、摆放指南、外观、波形 DIY、六种明暗/透感、高对比模式、小窗口。正式程序的设备名称取自 Windows；示例数据不写入正式音箱设置。

## 仍需在方便时检查的部分

- 实际 WebView2 窗口里的完整操作往返。本轮先前打开过原生预览，但完整原生检查没有通过验收；用户要求停止桌面操作后，没有再继续。
- 真实音箱的角色听感、低音分工、麦克风自动校准与取消后的恢复、长时间蓝牙播放漂移。
- 真正运行安装程序、升级覆盖，以及其他电脑上 WebView2 的环境。

音乐环绕是立体声扩展，不能称为原生独立 5.1 或杜比全景声。主音源继续由 Windows 原声播放；新分工作用于转发音箱。0.1 毫秒是调节步长，不表示蓝牙硬件能长期保持同等精度。
