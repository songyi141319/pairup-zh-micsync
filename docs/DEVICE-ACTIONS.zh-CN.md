# 本轮使用说明：轻声校准、单台试听与主音源

## 自动校准

打开“麦克风自动校准”后，已启用的音箱默认选中，主音源保留为对齐基准。点击开始才会播放测试音并使用麦克风。

- 从 20% 开始，将本轮选中的设备统一到同一档音量。
- 只有识别到声音过弱时，才按 30%、40%、50% 逐档尝试；提高后重新测量整组，避免混用不同条件。
- 50% 是自动上限。仍无法测量时停止，请检查音箱硬件音量、摆放、麦克风位置及连接。
- 连接中断、录音异常、失真或含混的回声不会靠继续升音量处理。
- 结束、取消或失败后恢复原设备音量、静音与声屿应用音量。设备中途断开导致恢复失败会明确提示，重新连接后请检查。

音量百分比并不等于房间里的实际响度；不同型号在相同百分比下可能仍有很大差别。本功能不能保证所有音箱都能自动校准成功，也不代表已定位此前每一次无声故障。

## 每台音箱单独试听

音箱卡片中的“试听”按该设备当前音量播放短铃声，再点“停止”可提前结束。无需先启用转发。试听时暂停向其他音箱转发，避免主音源上的铃声在所有音箱同时响起。

试听不自动提高音量。如果设备已断开、静音或音量为零，会提示检查。完成播放表示软件已把声音交给设备，是否真的出声仍需听一下。

## 设为主音源

在需要的设备卡片上选择“设为主音源”。程序会更换 Windows 的普通播放及音乐默认设备，重新建立转发；原主音源转为输出音箱。通话默认设备保持原值。

原有音色、分工和延迟数值保留。由于对齐基准改变，请重新校准。若音乐软件自己固定了输出设备，需要在音乐软件中改为“系统默认”。切换失败会尝试恢复原来的系统默认设备与播放连接，并说明恢复结果。

## 列表与标志

主音源和已启用音箱显示在上方，未启用设备默认折叠在下方，可展开后试听或启用。保留完整设备名称。

图标采用“声屿山形”：橙、紫、青音乐波形与环绕轨道构成透明玻璃球。启动时波纹向外扩散，循环约 3 秒；加载完成立即进入，不强制等待动画播完。系统关闭动画时显示静态图标。

## 本轮验证边界

本轮进行编译、静态审查及无窗口界面渲染。未自动播放测试音、录音、改变当前默认音源或音量；未把上述软件检查等同于实体音箱验收。
