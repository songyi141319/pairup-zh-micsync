# preview.5 启动显示修正

用户在 preview.4 遇到启动慢、白屏，拖动窗口后恢复显示。

本版移除启动时整个主窗口的透明度切换，并保持内嵌网页显示区域从创建时即可绘制。只隐藏旧界面，保留加载动画与加载失败回退。避免等待绘制完成时，却又把绘制窗口隐藏的启动顺序。

确认范围：代码检查发现上述启动顺序；用户“拖动后显示”的反馈与首次绘制问题吻合，但尚未在真实桌面完成重新启动验收。Release 编译通过，0错误、0警告。本轮没有运行自动化测试、操作桌面、播放音频或录音。

声音、音量、校准与设备管理逻辑沿用 preview.4。此次为启动显示的定向修正，不代表此前的实体音箱问题已经验证解决。
