声屿 · 多音箱音乐空间
0.4.0-preview.4 校准设置与设备恢复预览版

把蓝牙音箱、有线音箱组合起来听音乐。提供全屋同播、左右立体声、音乐环绕、低音辅助四种通用预设。
请先开启需要使用的音箱，完成同步，然后在“音场”页勾选音箱并指定摆放角色、设备能力。
预设只调整声音分工，不会更改音量、设备开关或已有延迟。所有音箱默认保持原声。
“摆放指南”内有左右位置、侧后位置、低音炮和小音箱的说明。也可阅读 docs\SHENGYU-GUIDE.zh-CN.md。
音乐环绕是普通立体声的模拟扩展，不是杜比全景声或原生 5.1 解码。
Windows 主音源直接播放原声，分工只用于其他已开启的音箱。

新界面：中文导航、浅色/深色主题、经典/更透/清晰三档透感、31 项玻璃参数、鼠标边缘光和彩色氛围。
可以关闭动态效果、关闭彩色氛围、减少透明度。外观设置只保存在本机。

Windows 10 / 11，64 位。安装包已包含 .NET，无需另装。
玻璃界面需要 Microsoft Edge WebView2 显示组件。多数 Windows 电脑已具备；缺少时保留原版界面继续使用。
显示组件官方下载：https://developer.microsoft.com/microsoft-edge/webview2/
解压版请保留 PairUp.App.exe 旁的整个 Web 文件夹，不能只复制一个 exe。

音量：整体音量会同步主音源及开启转发的音箱的 Windows 音量；单独音箱仍可微调。
再次调整体音量会统一各音箱音量。未开启转发的设备不受影响。
延迟：范围 0–3000 毫秒，可直接输入数字，或用 0.1 毫秒按钮微调。
麦克风校准：默认勾选已开启的输出；错误会区分静音、播放中断与收音问题。
校准时临时绕过频段分工和均衡，以免测试音被过滤；结束后恢复。

升级或卸载前，请等校准结束，再从系统托盘菜单正常“退出”。关闭窗口只是收起到托盘。
安装器不强制结束软件，不自动启动新版本。
增强版安装到当前用户 Programs\PairUp-Chinese；原版与增强版共用 %APPDATA%\PairUp\settings.json，请只运行一个。

本轮完成编译、静态审查和后台界面渲染，未运行自动测试或操作音频。真实音箱声场、麦克风校准及长时间蓝牙同步仍需在你的房间试听。
0.1 毫秒是可调步长，不代表蓝牙会一直维持此精度。
