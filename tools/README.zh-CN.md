# 专门检查与诊断工具

- `SyncChecks`：不打开实体音频设备，检查延迟处理、细调、识别和失败保护。
- `AcousticProbeCheck`：供开发排查使用；会录音并播放一次短测试音。临时静音其它音乐和已运行 PairUp 的输出会话，结束后恢复。仅打印识别时间、清晰程度和时间覆盖等数据，不保存或上传录音。
- `AcousticObserver`：供开发排查参考声音的时间记录使用；不播放测试音，不打开麦克风，仅打印音源录音的统计数据。录音只在内存中。

这些工具不属于日常操作。实际自动校准请使用主程序的“麦克风自动校准”窗口。

公开版诊断工具不保存本机麦克风的唯一标识。`AcousticProbeCheck` 必须通过 `--microphone <本机设备标识>` 选择输入；`--help` 只显示用法，`--sessions-only` 只查看系统音频会话。不提供麦克风参数时不会播放测试音或打开麦克风。实际测量必须先得到用户当前同意。
