# 声屿音场离线检查

本程序只处理内存中的合成声音，并在编译输出目录创建独立的临时设置文件；不打开、枚举、录制或播放真实音频设备。测试直接编译实际音频与设置源文件，不依赖界面工程。

在仓库根目录运行：

```powershell
& 'C:\Users\Admin\Downloads\PairUp-Localization-v0.3.6\dotnet-sdk\dotnet.exe' run --project tools/SpatialChecks/SpatialChecks.csproj -p:NuGetAudit=false
```

覆盖内容：默认原声逐位一致；原来的声道转换、重采样和均衡器一致；左右、中央、低音与后侧分配；单声道输入和单声道输出；高低通；负增益与滤波瞬态限幅；无效数值；读取边界更新；校准期间旁路与结束恢复；不支持的多声道格式；旧设置兼容、新设置往返保存与损坏设置保护；主音源及校准期间的修改限制。

## 声音分配约定

所有公式使用处理前的左声道 L 和右声道 R。默认原声保留原来的 L/R。前左取 L，前右取 R；中央与低音取 `(L + R) × 0.5`；后左取 `0.65L − 0.35R`，后右取 `0.65R − 0.35L`。分配后的声音复制到该设备的两个声道。单声道视为 `L = R`，后侧保留 30% 音量，其他位置保留单声道原有音量。

低频截止用于去除更低的频率，高频截止用于去除更高的频率；0 表示关闭。低音位置本身不猜测设备能力，低音预设应另设高频截止。截止范围为 20–20000 Hz，实际滤波截止最高不超过音源采样率的 49%，避免低采样率时产生无效滤波系数。增益范围为 −24 到 0 dB。

矩阵系数绝对值之和最多为 1，空间处理不会放大混音；活动音场在高低通和增益之后限制到音频满幅范围 `[-1, 1]`，避免滤波瞬态溢出。默认原声和校准旁路逐样本保留原音。原有均衡器位于音场之后，用户之前设置的均衡器增强仍会生效；校准期间暂时旁路它，结束后恢复。

这是立体声音乐的矩阵分配与频率分工，不能当作独立原生 5.1 声道或杜比全景声解码。离线检查证明计算与状态恢复，不代表真实蓝牙设备的听感或房间中的同步测量已经通过。
